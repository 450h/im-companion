# MED 222 IM Companion

**A free Windows study app for Internal Medicine (Med 611).**
**It follows your exam blueprint, tells you what to study today, tests you in the exam's format, and shows you exactly where to study for every question you miss.**

## What it does
| | |
|---|---|
| 🗓️ **Study planner that fills itself in** | Midterm plan (exam **Tue 1 Dec 2026**: EMQs + OSPE) and Final plan (exam **Tue 5 Jan 2027**: MCQs). Sun–Thu study days, Fri/Sat rest, Learn → Consolidate → Final revision phases, generated from the day you start. Progress is logged automatically as you read, review and answer. |
| 📚 **Summaries for every blueprint topic** | Organised by the blueprint's learning objectives, with a **citation on every point** (book · edition · chapter · page) so you can check it in the book. |
| 🃏 **Flashcards** | Spaced repetition, with due cards capped before your exam date. |
| ✅ **Worked examples → section quizzes → topic quizzes → chapter exams → mock exams** | EMQs in the midterm style, MCQs in the final style. |
| 🧭 **"Where should I study?"** | Every wrong answer links to the exact summary section and book page. |
| 📖 **EMQ Volumes practice** | Open *EMQs for Medical Students* Vols 1–3 at the page the app shows, answer in the app's answer sheet, and get marked with explanations. |
| 🔁 **Spaced reviews + weak areas** | Reviews at 1, 3, 7 and 14 days; confidence ratings; weak topics (< 60%) drilled automatically. |
| 🔒 **Private** | No account, no tracking. Your progress stays on your PC (with automatic backups and export). |

## About the sources
This app **does not contain** any textbook, figure or question from the books it cites. All summaries, flashcards and questions are original, written for this course's blueprint, and **cite** the books you already have (Davidson's 24e, Kumar & Clark 10e, Pocket Medicine 8e, Step-Up 6e, First Aid Step 2 CK 11e, Talley & O'Connor 8e, Goldberger's ECG, Washington Manual 36e, Zero to Finals, IM in 25 days, EMQs for Medical Students Vols 1–3). It isn't affiliated with or endorsed by their authors or publishers, or by the college.

> ⚠️ **For exam study only. Not clinical guidance.** Every summary point cites its source, and each topic is checked against those pages before release. If something looks wrong, check the cited page and report it with the ⚑ button.

## Install
1. Download `MED-222-IM-Companion-Setup-x.y.z.exe` from [**Releases**](https://github.com/450h/im-companion/releases/latest) (or the portable `.exe` if you can't install software).
2. Windows may show *"Windows protected your PC"* because the app isn't code-signed. Click **More info → Run anyway**. You can verify the file against `SHA256SUMS.txt` first.
3. When a new version with more content is out, the app shows a **"New version available · Download"** banner. Download the new installer and run it over the old one. Your progress is kept.

## Privacy
The app sends nothing about you anywhere. Its only network request is checking this repository's GitHub Releases for a newer version (you can turn that off in Settings), and GitHub sees your IP address as with any download. Error reports open a GitHub issue in your browser, so you see exactly what's sent.
