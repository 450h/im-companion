# Security Policy

MED 222 IM Companion stores your study progress only on your PC. Its only network activity is checking this repository's GitHub Releases for a newer version. It never downloads or installs anything by itself.

## Reporting a vulnerability
If you find a vulnerability, please **report it privately** through GitHub's **Security → Report a vulnerability** on this repository. Don't open a public issue. Examples:
- a way for an imported file or content text to execute code
- a way to make the "new version available" banner point somewhere other than this repository's releases

Include the version, the steps to reproduce and the impact. Fixes ship as a new release, with the impact described in the release notes.

## Copyright concerns
This project ships only original content that cites published books; no book text, figures or questions are included. If you're a rights holder and believe something here infringes your work, open an issue or a private report naming the file and content. It will be reviewed and, if needed, removed within 24 hours.
